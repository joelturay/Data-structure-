# Stack-Based Arithmetic Expression Evaluator

## Overview
This project is a Python command-line program for evaluating arithmetic expressions from a text file. It demonstrates a custom **stack** data structure and uses stack operations to check parentheses and help evaluate expressions.

## Files
- `stack.py` — Python source code containing the `Stack` class, expression parser/evaluator, file-processing logic, and `main()` function.
- `input.txt` — sample test expressions. Each expression should be written on its own line. Lines made of at least two hyphens are treated as visual separators.
- `output.txt` — results generated by the program. Successful expressions produce a number; invalid expressions produce an error message.

## Requirements
- Python 3 (Python 3.8 or later recommended).
- No third-party packages are required. The program uses Python's standard library.

## How to Run

### 1. Keep the files together
Place `stack.py`, `input.txt`, and `output.txt` in the same folder.

### 2. Open a terminal in that folder
On Windows, open the folder in File Explorer, click the address bar, type `cmd`, and press Enter. Alternatively, use `cd` in Command Prompt to move to the project folder.

### 3. Run the program with the default filenames
```bash
python stack.py
```
If your system uses the Python launcher, you can also try:
```bash
py stack.py
```
The program reads `input.txt` from the same directory and writes results to `output.txt`.

### 4. Run with custom file paths (optional)
The program accepts an input path followed by an output path:
```bash
python stack.py input.txt output.txt
```
For example, on Windows:
```bash
python stack.py "C:\Users\YourName\Desktop\StackExpression\input.txt" "C:\Users\YourName\Desktop\StackExpression\output.txt"
```
Replace the example paths with the actual locations on your computer.

## Input File Format
- Use one arithmetic expression per line.
- Supported operators: `+`, `-`, `*`, `/`.
- Parentheses `(` and `)` can group expressions.
- Whole numbers and decimal numbers are supported.
- Spaces between tokens are allowed.
- A line made of two or more hyphens, such as `-----`, is preserved as a separator and is not evaluated.
- Blank lines are skipped.

Example:
```text
5 + 6 * 2
-----
(9 - 3) * 4
-----
20 / 8
```

## Output File Format
The output file contains the calculated result or a line beginning with `Error:` for each processed expression. Separator lines are retained, and blank input lines are skipped. Existing output content is replaced each time the program runs.

Example:
```text
17
-----
24
-----
2.5
```

## Supported Features
- Custom `Stack` class with `push`, `pop`, `peek`, `is_empty`, `size`, and `to_list`.
- Tokenization of numbers, arithmetic operators, and parentheses.
- Parenthesis matching checks.
- Multiplication and division precedence over addition and subtraction.
- Basic support for signed numbers such as `-3 + 10` and `9 - -4`.
- Error messages for division by zero, unmatched parentheses, empty parentheses, misplaced operators, missing operators, unsupported characters, and malformed decimal numbers.
- Processes each expression independently so one invalid line does not stop later test cases.

## Assumptions and Limitations
- Only `+`, `-`, `*`, `/`, and round parentheses are supported.
- Variables, exponentiation, mathematical functions, and implicit multiplication (for example, `2(3 + 4)`) are not supported.
- The implementation is intended for simple arithmetic expressions and is not a full mathematical parser.
- A unary minus directly before a parenthesized group (for example, `-(2 + 3)`) is not handled as a general supported syntax by the current parsing logic. Review such expressions carefully and extend the parser if full support is required.
- Results are formatted to a maximum of four decimal places, with unnecessary trailing zeros removed.
- The program skips ordinary spaces; tabs or other whitespace may require additional handling.

## Troubleshooting
- **Python is not recognized:** install Python 3 and ensure it is added to PATH, or use the full path to `python.exe`.
- **Input file not found:** make sure `input.txt` is in the same folder as `stack.py`, or pass the correct input path as the first argument.
- **Output is not updated as expected:** check that the output path is correct and that the file is not open in an application that prevents writing.
- **Unexpected result for an expression:** check the supported operators and syntax, then add a test case to `input.txt`.
